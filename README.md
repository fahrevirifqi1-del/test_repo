# Waveform

A modern music discovery frontend built with HTML, CSS, and vanilla JavaScript. No installation or dependencies required.

Run `npm run dev`, then open **http://localhost:3000**. You can also open `index.html` directly.

Includes responsive layouts, mood filters, search, saved mixes, a music player with original browser-generated instrumental previews, volume, seek, shuffle, repeat, and keyboard shortcuts. Saved mixes use device-local storage. Playlist shortcuts are session-local and point to your saved mixes. The Google font is optional; the site falls back to a system font offline.

Press `/` to search or `Space` to play and pause. All branding and music are fictional demo content. No backend or external music service is connected.

Run `npm run check` for JavaScript syntax validation.
